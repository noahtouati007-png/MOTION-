# Boissons Galzin × Cafés Folliet (charte Galzin)

Refonte des visuels Folliet (affiches 50x70, carte A5, stop-trottoir) dans la charte du `_kit-galzin`.

| Fichier Illustrator (SVG) | Format |
|---|---|
| `galzin-boissons-chaudes-50x70.svg` | Affiche 50 x 70 cm |
| `galzin-boissons-froides-50x70.svg` | Affiche 50 x 70 cm |
| `galzin-carte-boissons-chaudes-A5.svg` | Carte A5 (14,8 x 21 cm) |
| `galzin-stop-trottoir-recto-verso.svg` | Stop-trottoir 54 x 125 cm, recto (groupe `RECTO`) et verso (groupe `VERSO`) côte à côte, 6 cm d'écart |

- Prix : ovales vides (groupe `PRIX`), à compléter dans Illustrator.
- Photos : intégrées dans les SVG ; les originaux détourés sont dans `images/`.
- Aperçus PNG dans `apercus/` (polices de remplacement : Impact et Heroica non installées sur la machine de rendu).
- `python3 build.py` régénère tout.
