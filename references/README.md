# Références

Fichiers sources pour reproduire la vidéo TikTok de motion design sur un son d'Ino Casablanca.

| Fichier attendu | Contenu |
| --- | --- |
| `reference.mp4` | La vidéo TikTok de référence (style à reproduire) |
| `son.mp3` (ou `.wav`, `.m4a`) | Le morceau d'Ino Casablanca à utiliser |

Pour les ajouter depuis ton ordinateur :

```bash
git pull
cp ~/Téléchargements/ta-video.mp4 references/reference.mp4
cp ~/Téléchargements/ton-son.mp3 references/son.mp3
git add references && git commit -m "Ajoute la vidéo de référence et le son" && git push
```

Tu peux aussi simplement envoyer les deux fichiers dans le fil du projet : Claude les rangera ici.
